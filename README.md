# Dad Joke Showdown

An entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)
bounty on [make.fun](https://make.fun): one original dad joke, written by a
program to `/output/entry.txt`.

## The joke

> I told the dishwasher I loved it. It said, 'Thanks, but please stop loading me with all your problems.'

103 characters. One clean pun — *loading* the dishes, and *loading* someone
with your problems — delivered straight-faced, punchline at the end.

## Run it

```sh
python3 main.py
```

It validates the joke (UTF-8, 1–200 characters, not only whitespace) and
writes it byte for byte to `/output/entry.txt` (override the directory with
`OUTPUT_DIR`).
